# 도트립 · dotrip

도트립은 혼자 여행할 때도, 동행과 함께할 때도 쓸 수 있는 여행 가계부를 목표로 합니다.
여행 중에는 현지에서 얼마를 썼는지 바로 적고, 나중에는 어디에서 쓴 돈인지 지도와 이동 경로를 따라 살펴봅니다.
귀엽고 통통한 도트 수달 한 마리가 여행 기록에 반응합니다.

## 이름

`do`를 ‘도’, `trip`을 ‘트립’으로 읽으면 **도트립**입니다.
영문 이름 `dotrip`에는 `dot`과 `trip`이 가운데 `t`를 공유하는 말장난도 담았습니다.

| --- | --- |

| “이 택시비에서 제 몫은 얼마인가요?” | 혼자 쓴 돈은 개인 지출로 남기고, 함께 쓴 돈은 동행과 나눕니다. |
| “오늘 어디를 거쳐 왔나요?” | 지도에서 방문한 장소와 이동 경로를 보고, 각 장소에서 쓴 돈을 확인합니다. |

화면은 도트 게임처럼 보이고, 돈을 적는 과정은 한 손으로도 간편해야 합니다.
수달 한 마리의 움직임을 부드럽게 다듬는 것이 시각 디자인의 목표입니다.
애니메이션이 재생되는 동안에도 다음 기록을 시작할 수 있어야 합니다.

## 첫 화면에서 시도해 볼 흐름

도쿄에서 커피 한 잔에 480엔을 쓴 상황을 예로 듭니다.

1. 홈에서 **지출 추가**를 누르면 여행 통화인 엔화가 선택된 상태로 숫자 키패드가 열립니다.
2. `480`을 입력해 원화 환산액을 확인하고 저장하면 오늘 기록에 한 줄이 생깁니다.
3. 장소와 메모는 나중에도 붙일 수 있습니다. 동행과 나눌 지출에만 **나누기**를 선택합니다.

게임 요소로는 장소를 붙인 기록마다 수달이 지도 핀 옆에 조약돌을 하나씩 놓는 연출을 제안했습니다.
하루의 기록이 쌓이면 조약돌이 그날 다닌 길을 보여줍니다.
이 입력 흐름과 조약돌 연출은 첫 시안을 위한 아이디어입니다.
환산에 쓸 환율의 기준, 동행과 비용을 나누는 세부 방식, 지도에 경로를 남기는 방법은 아직 열려 있습니다.
